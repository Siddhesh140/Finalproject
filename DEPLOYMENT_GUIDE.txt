SECTION 1: CRITICAL - REQUIRED FOR AI FEATURES
================================================================================

You need an API key to enable AI features (transcription, RAG chat, quiz generation).

---- STEP 1: Get Google Gemini API Key ----
1. Go to: https://aistudio.google.com/app/apikey
2. Click "Create API Key"
3. Copy the key (starts with "AI...")

---- STEP 2: Configure Environment ----
1. Create a file at: backend/.env
2. Add these contents:

    # REQUIRED - Get from https://aistudio.google.com/app/apikey
    GOOGLE_API_KEY=your_api_key_here
    
    # Optional settings
    llm_provider=google
    
3. Restart the backend:
   pkill -f uvicorn
   cd backend && source .venv/bin/activate && uvicorn app.main:app --reload --port 8000

---- VERIFY ----
Test the backend health:
curl http://localhost:8000/health

If you see "No valid AI API key" warning, the key isn't set correctly.

SECTION 4: FRONTEND - AUTH GUARD (Recommended)
================================================================================

Currently all routes are accessible. Add auth protection.

---- CURRENT STATE ----
- Anyone can access /dashboard, /library, etc.
- No check if user is logged in

---- RECOMMENDED FIX ----
Add ProtectedRoute component in App.jsx:

// Already have AuthContext, just add redirect if not logged in

Edit video-rag-app/src/App.jsx and add a wrapper:

import { useAuth } from './context'
import { Navigate } from 'react-router-dom'

function ProtectedRoute({ children }) {
  const { user, loading } = useAuth()
  if (loading) return <div>Loading...</div>
  if (!user) return <Navigate to="/auth" />
  return children
}

Then wrap protected routes:
<Route path="/dashboard" element={<ProtectedRoute><Dashboard /></ProtectedRoute>} />

SECTION 5: VIDEO PROCESSING - LOCAL MODEL (Optional)
================================================================================

Currently video processing is simplified. For real transcription:

---- OPTION A: Use Cloud Whisper (Free tier) ----
Already integrated via openai-whisper. With GOOGLE_API_KEY set, it works.

---- OPTION B: Use Local Whisper (100% Free) ----
1. Install faster-whisper:
   pip install faster-whisper

2. Modify backend/app/services/video_processor.py to use local model

This requires good hardware (8GB+ RAM). For demo, cloud whisper is fine.

SECTION 8: COMMON ISSUES & FIXES
